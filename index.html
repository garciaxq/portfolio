Projeto em destaque

NexaFin

Gestão financeira pessoal

Desenvolvi o NexaFin para reunir receitas, despesas e compromissos futuros em uma mesma aplicação. A proposta é facilitar a leitura do mês, incluindo o que já foi pago e o que ainda está pendente.

  • Lançamentos e acompanhamento do saldo mensal
  • Controle de financiamentos e compras parceladas
  • Análises de receitas e despesas por categoria

JavaScript · Node.js · PostgreSQL
HTML · CSS · Vercel

Testar demonstração ↗

Sem cadastro. Os dados são fictícios e as alterações não ficam salvas.

Mais sobre o desenvolvimento +

Aplicação completa

O projeto reúne interface responsiva, autenticação, persistência em banco de dados, regras financeiras e integração de pagamento.

Ambiente de demonstração

A demonstração é separada da aplicação principal. Ela permite conhecer os lançamentos, as análises e os controles financeiros com dados de exemplo.

Tecnologias na prática

JavaScript e Node.js no desenvolvimento, PostgreSQL para os dados e publicação na Vercel.
